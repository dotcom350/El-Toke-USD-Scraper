Cuba's exchange rates, as an API. Las tasas de cambio de Cuba, como API.

A tiny, free JSON API that tracks the informal (street) and official bank rates for every currency elTOQUE publishes — USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP, CHF, DKK, JPY, NOK, SEK, AUD, CNY and PAB — refreshed automatically so you never have to scrape it yourself. Una API JSON pequeña y gratuita que sigue la tasa informal (calle) y las tasas oficiales de bancos de todas las monedas que publica elTOQUE — USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP, CHF, DKK, JPY, NOK, SEK, AUD, CNY y PAB — actualizada automáticamente para que no tengas que scrapear nada tú mismo.

Try it

Pruébala

GET the current rate. No authentication, no rate limit headers to worry about.

Haz GET a la tasa actual. Sin autenticación, sin headers de rate limit de qué preocuparte.

# GET the latest USD rate
curl {{ request.base_url }}api/v1/dolar
import requests

resp = requests.get("{{ request.base_url }}api/v1/dolar")
data = resp.json()
print(data["data"]["informal"]["usd_to_cup"])
const res = await fetch("{{ request.base_url }}api/v1/dolar");
const { data } = await res.json();
console.log(data.informal.usd_to_cup);

Endpoints

Endpoints

Endpoint DescriptionDescripción
GET/api/v1/dolar Informal + official USD rates, as cached JSON.Tasas de USD informal + oficiales, como JSON cacheado.
GET/api/v2/rates All 16 currencies elTOQUE tracks, in their own order.Las 16 monedas que sigue elTOQUE, en su propio orden.
GET/api/v2/rates/{code} A single currency by code (USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP, CHF, DKK, JPY, NOK, SEK, AUD, CNY, PAB).Una sola moneda por código (USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP, CHF, DKK, JPY, NOK, SEK, AUD, CNY, PAB).

GET/api/v1/health Service status and last successful scrape time.Estado del servicio y hora del último scrape exitoso.
GET/docs Interactive Swagger / OpenAPI docs.Documentación interactiva Swagger / OpenAPI.

Connect via MCP

Conecta vía MCP

This API is also a Model Context Protocol (MCP) server, so agents like Claude can query rates as tools instead of raw HTTP. No API key. It exposes list_currencies, get_all_rates and get_rate(code).

Esta API también es un servidor Model Context Protocol (MCP), así que agentes como Claude pueden consultar las tasas como tools en vez de HTTP crudo. Sin API key. Expone list_currencies, get_all_rates y get_rate(code).

# Add this server to Claude Code
claude mcp add --transport http cuba-rates {{ request.base_url }}mcp/
{
  "mcpServers": {
    "cuba-rates": {
      "type": "http",
      "url": "{{ request.base_url }}mcp/"
    }
  }
}

All currencies (v2)

Todas las monedas (v2)

Every currency elTOQUE prices, in elTOQUE's own order. Some only trade informally (MLC, ZELLE, CLA); some only have an official bank rate (GBP, CHF, DKK, JPY, NOK, SEK, AUD, CNY, PAB).

Todas las monedas que precia elTOQUE, en el orden propio de elTOQUE. Algunas solo se cambian de forma informal (MLC, ZELLE, CLA); otras solo tienen tasa bancaria oficial (GBP, CHF, DKK, JPY, NOK, SEK, AUD, CNY, PAB).

# GET all currencies
curl {{ request.base_url }}api/v2/rates

# GET a single currency
curl {{ request.base_url }}api/v2/rates/EUR

Histórico

Run your own copy

Corre tu propia copia

Clone the repo, add your free Firecrawl API key, and start it with Docker Compose:

Clona el repo, agrega tu API key gratuita de Firecrawl, y arráncala con Docker Compose:

git clone https://github.com/dotcom350/El-Toke-USD-Scraper.git
cd El-Toke-USD-Scraper
cp .env.example .env   # add your FIRECRAWL_API_KEY
docker compose up -d --build
