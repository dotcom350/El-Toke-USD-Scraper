Cuba's exchange rates, as an API. Las tasas de cambio de Cuba, como API.

A tiny, free JSON API that tracks the informal (street) and official bank rates for every currency elTOQUE publishes — USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP and CHF — refreshed automatically so you never have to scrape it yourself. Una API JSON pequeña y gratuita que sigue la tasa informal (calle) y las tasas oficiales de bancos de todas las monedas que publica elTOQUE — USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP y CHF — actualizada automáticamente para que no tengas que scrapear nada tú mismo.

Try it

Pruébala

GET the current rate. No authentication, no rate limit headers to worry about.

Haz GET a la tasa actual. Sin autenticación, sin headers de rate limit de qué preocuparte.

# GET the latest USD rate
curl {{ request.base_url }}api/v1/dolar
import requests

resp = requests.get("{{ request.base_url }}api/v1/dolar")
data = resp.json()
print(data["data"]["informal"]["usd_to_cup"])
const res = await fetch("{{ request.base_url }}api/v1/dolar");
const { data } = await res.json();
console.log(data.informal.usd_to_cup);

Endpoints

Endpoints

EndpointEndpoint DescriptionDescripción
GET/api/v1/dolar Informal + official USD rates, as cached JSON. Tasas de USD informal + oficiales, como JSON cacheado.
GET/api/v2/rates All 9 currencies elTOQUE tracks, in their own order. Las 9 monedas que sigue elTOQUE, en su propio orden.
GET/api/v2/rates/{code} A single currency by code (USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP, CHF). Una sola moneda por código (USD, EUR, MLC, CAD, MXN, ZELLE, CLA, GBP, CHF).
GET/api/v1/health Service status and last successful scrape time. Estado del servicio y hora del último scrape exitoso.
GET/docs Interactive Swagger / OpenAPI docs. Documentación interactiva Swagger / OpenAPI.

All currencies (v2)

Todas las monedas (v2)

Every currency elTOQUE prices, in elTOQUE's own order. Some only trade informally (MLC, ZELLE, CLA); some only have an official bank rate (GBP, CHF).

Todas las monedas que precia elTOQUE, en el orden propio de elTOQUE. Algunas solo se cambian de forma informal (MLC, ZELLE, CLA); otras solo tienen tasa bancaria oficial (GBP, CHF).

Run your own copy

Corre tu propia copia

Clone the repo, add your free Firecrawl API key, and start it with Docker Compose:

Clona el repo, agrega tu API key gratuita de Firecrawl, y arráncala con Docker Compose:

git clone https://github.com/dotcom350/El-Toke-USD-Scraper.git
cd El-Toke-USD-Scraper
cp .env.example .env   # add your FIRECRAWL_API_KEY
docker compose up -d --build
